# ============================================================================
# Root requirements for the complete local PDF extraction project.
#
# Python required: 3.11 or 3.12 for the FULL stack.
# Python 3.8 / 3.9 will only work for Stage 2 (Pipeline/) — the Stage-1 OCR
# stack (transformers, vLLM, GLM-OCR) needs Python >= 3.10.
#
# scripts/setup_env.sh auto-detects your Python version:
#   - Python 3.10+ -> installs everything below
#   - Python 3.8/3.9 -> installs only Pipeline/requirements.txt (Stage 2 only)
#
# Force a profile: STAGE=2 ./scripts/setup_env.sh   (Stage 2 only, slim)
#                  STAGE=full ./scripts/setup_env.sh (full stack)
#
# Notes:
#   - Ollama itself is NOT a pip package. Install it separately:
#       curl -fsSL https://ollama.com/install.sh | sh
#       ollama pull qwen2.5:32b
#   - For GLM-OCR self-hosted serving you also need vLLM and the latest
#     transformers source build. Those are NOT in this file:
#       uv pip install -U vllm --torch-backend=auto \
#           --extra-index-url https://wheels.vllm.ai/nightly
#       uv pip install git+https://github.com/huggingface/transformers.git
#   - For GPU PyTorch, install the CUDA-specific torch wheel separately.
# ============================================================================
